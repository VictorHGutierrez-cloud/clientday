# Factorial Client Day

Present from `index.html`. Arrow keys move between slides. Click the right edge to go forward and the left edge to go back. On a film, press play. Leaving the slide pauses it.

The three films:

- Talent and operations, 15 minutes. Roles, time, and the week of work.
- Finance, 11 minutes. Headcount, expenses, and the plan.
- One, 7 minutes. The agent on company data.

Host notes, including the Kahoot answers, are in `host.html`. Do not show that page in the room.

`Factorial-Client-Day.pdf` is the same story without the films. A PDF cannot play them.

The Talent and operations file in `videos/` is a 720p copy. The original is 141MB, and GitHub rejects files over 100MB. One and Finance are the original files.

To publish the deck, turn on GitHub Pages for this repo from the `main` branch, root folder. The address will be `https://victorhgutierrez-cloud.github.io/clientday/`.
